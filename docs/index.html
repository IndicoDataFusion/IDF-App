IndicoDataFusion

One unified view for your Indico conference data.

IDF aggregates events, contributions, and abstracts from one or more Indico instances into a single, offline-capable desktop application — built for organizers, reviewers, and observers alike.

Why IDF

Conference data shouldn't live in silos.

Large scientific conferences rely on Indico to manage events, contributions, and the review process — but teams often span multiple Indico instances, and reviewers need access to data offline, between sessions, or without a live connection.

IDF bridges that gap. It fetches, caches, and presents data from any number of Indico instances in one consistent interface, whether you're managing a programme committee, submitting reviews, or simply browsing accepted abstracts.

Capabilities

Everything you need. Nothing you don't.

Multi-instance aggregation

Connect to multiple Indico servers simultaneously. Switch data sources in seconds — no relogging, no duplication.

Offline-capable cache

Fetched data is cached locally. Browse events, contributions, and abstracts without an active network connection.

Role-aware modes

Automatically adapts its interface depending on whether you are a conference manager, a programme-committee reviewer, or a read-only observer.

Inline review workflow

Submit, view, and edit your own reviews directly inside the app. Vote on questions and track your review status at a glance.

Abstract stats & charts

Visualize submission trends, track review progress, and explore contribution statistics with built-in analytics charts.

Secure token storage

API tokens are stored in the OS keyring — Keychain on macOS, Secret Service on Linux, Credential Manager on Windows. Never in plain-text files.

Workflow

Up and running in minutes.

  1. 01

    Install the app

    Download the native installer for Windows, macOS, or Linux from the releases page. No runtime dependencies required.

  2. 02

    Add an Indico API token

    Generate a token in your Indico profile, then paste it into the IDF Setup Wizard. The secret is saved immediately to your OS keyring.

  3. 03

    Configure a data source

    Point IDF at one or more Indico instances. Each data source can have its own token, mode, and cache settings.

  4. 04

    Browse, review, or export

    Navigate events and contributions in the sidebar. Submit reviews, explore abstract stats, or export a redacted abstracts file for offline distribution.
