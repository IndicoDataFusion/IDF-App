From download to data

Up and running in four steps.

Install the native package, configure a source, and let the local cache make later reads faster.

  1. 01

    Install IDF

    Download the Windows installer, macOS package, or Linux archive or AppImage.

  2. 02

    Open data sources

    Complete the Setup Wizard on first launch, or use Settings → Data Sources.

  3. 03

    Connect or choose a file

    Add a token, base URL, and event ID for live data—or choose an abstracts export for browsing without a token.

  4. 04

    Open the programme

    Visit Event Info, Abstracts, or Contributions and let the initial load populate the local cache.
